# Первое включение · PCStream 1.7

Для HelloCubic-Lite с ESP8266, 4 МБ flash и экраном ST7789 240×240.
Одна универсальная сборка для совместимых плат; личные Wi-Fi и API-токен
в файл прошивки не включаются.

1. Подключите питание. На ненастроенном кубике появится QR-код Wi-Fi.
2. Отсканируйте его камерой телефона и подтвердите подключение.
   Сеть: **GeekMagic**, пароль: **`$str0ngPa$$w0rd`**.
   Имя и пароль также напечатаны под QR-кодом на экране кубика.
3. Откройте предложенное телефоном окно настройки. Если оно не появилось,
   через 8 секунд после подключения кубик покажет QR-код страницы.
   Можно открыть **http://192.168.4.1/setup** вручную.
4. Нажмите «Найти сети рядом», выберите домашнюю сеть **2,4 ГГц**
   в поле названия либо введите название вручную. Введите её пароль
   и нажмите «Подключить кубик». Подождите до 30 секунд.
5. На странице появится подтверждение сохранения и домашний IP кубика.
   Для нового устройства раскройте «Ключ подключения CubeDesk» и сохраните
   API-токен в CubeDesk: «Подключение» → «Настройка потокового режима».
   Затем укажите домашний IP. При обновлении уже подключённого кубика
   прежний ключ сохраняется.
6. Верните телефон в домашнюю сеть. Через 30 секунд точка настройки закроется.
   Содержимое уже открытой страницы, включая ключ, остаётся доступно для копирования.

Если настраиваете несколько кубиков с одинаковым именем сети, включайте их
по одному. Это исключает подключение телефона к соседнему ненастроенному кубику.

## После настройки

При обычном включении кубик использует сохранённую сеть. QR-код первого
подключения не заменяет домашние настройки. При потере роутера кубик
продолжает попытки соединения; только через 120 секунд поднимает дополнительную
сеть настройки. После восстановления домашнего Wi-Fi она закрывается.

Окно настройки открывается средствами iOS/Android и зависит от настроек телефона.
Резервные QR-код страницы и адрес не требуют автоматического открытия окна.
Интернет и внешние сайты для настройки не используются.

## Сборка и обновление

`python -m platformio run -d firmware`, затем `python package_firmware.py`.
Получится `dist/HelloCubic-PCStream-universal.bin` и JSON с SHA-256.
Упаковщик проверяет отсутствие локальных приватных загрузочных значений.
Приватный `pcstream_boot.h` игнорируется, если явно не задан флаг
`PCSTREAM_PRIVATE_DEFAULTS`; такой образ не пройдёт проверку публичной сборки.

Первое включение создаёт индивидуальный API-токен, обновление сохраняет существующий.
Страница настройки принимает изменение сети только через интерфейс точки GeekMagic
и с сессионным nonce из формы. Ключ CubeDesk не выдаётся посетителям
страницы через домашнюю сеть. Резервный `/legacyupdate` защищён HTTP Basic:
имя `cubedesk`, пароль — действующий API-токен. Основной API использует Bearer.
Общий пароль точки настройки выбран намеренно; он не является индивидуальным
ключом управления устройством.

Обновление устанавливает только firmware.bin, без форматирования LittleFS
или стирания сохранённой конфигурации. OTA-помощник поддерживает флаг `--universal`
и перед записью проверяет манифест, SHA-256 и действующую авторизацию кубика.

## Проверка этой версии

Прошивка собрана и установлена на рабочий кубик. Пройдены 34 теста CubeDesk,
проверка JS формы, проверка интерфейса в браузере и три программные перезагрузки
с сохранением сети/ключа и возвращением на домашний IP. Проверены ограничения
страницы настройки со стороны домашнего LAN. QR-макеты проверены OpenCV при 240×240
на эталонном Python-порте того же Nayuki v1.8.0. Через стекло физического кубика
и на реальном телефоне первый запуск пока не проверен; заводской сброс рабочего
устройства ради этой проверки не выполнялся.

QR-код: Project Nayuki QR-Code-generator v1.8.0, C, MIT (лицензия в исходных файлах
`firmware/lib/qrcodegen`). Сетевой портал использует DNSServer из ESP8266 Arduino 3.1.2.

Источники: [Nayuki](https://www.nayuki.io/page/qr-code-generator-library),
[пример captive portal ESP8266](https://github.com/esp8266/Arduino/blob/3.1.2/libraries/DNSServer/examples/CaptivePortal/CaptivePortal.ino),
[окно сети на iPhone](https://support.apple.com/en-gb/102554).
