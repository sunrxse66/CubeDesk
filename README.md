# CubeDesk

Ваш GeekMagic HelloCubic-Lite — маленький экран для любимых GIF, красивых часов, погоды и питомца Моти.

**[Скачать для Windows](https://github.com/sunrxse66/CubeDesk/releases/latest)** · [Первый запуск](CUBEDESK.md) · [Первая прошивка](FIRST_FLASH.md) · [Что нового](CHANGELOG.md)

## Быстрый старт

1. В последнем релизе скачайте **CubeDesk-Windows.zip** и распакуйте в обычную папку.
2. Запустите **CubeDesk.exe**. Панель откроется в браузере на вашем ПК; Python и права администратора не нужны.
3. Подайте питание на кубик. Если PCStream ещё не настроена, отсканируйте QR на экране и выберите домашний Wi-Fi **2,4 ГГц**. Имя сети и пароль также показаны текстом.
4. В CubeDesk сохраните ключ подключения со страницы настройки, введите IP с экрана кубика и нажмите «Подключить».
5. Добавьте файлы в медиатеку или откройте «Виджеты».

При уже настроенном PCStream повторная настройка сети не требуется. Компьютер и кубик должны находиться у одного роутера.

В разделе **«Работа в фоне»** включите **«Запускать с Windows»** и оставьте включённым **«Продолжать последний показ»**. После входа в Windows CubeDesk сам вернёт выбранный файл, папку, виджет или питомца, не открывая браузер. Управление доступно через значок рядом с часами. Пауза сохраняется; недоступный кубик или диск программа подождёт. Оставьте распакованный EXE в постоянной папке.

## Что умеет

- **Картинки и длинные GIF с ПК.** Выбранный файл повторяется отдельно или воспроизводится вся папка. Размер GIF не ограничивается памятью кубика: по сети передаются кадры.
- **Три режима детализации.** «Плавно» 80×80, «Баланс» 120×120, «Чётко» 240×240; все заполняют экран. В плавном режиме на тестовом устройстве получено около 20 кадров/с; результат зависит от сети и анимации.
- **Часы и погода.** Мягкие градиенты, крупные цифры, выбор города, кэш последнего прогноза.
- **Питомцы Моти и Момо.** Выберите котика и нажмите «Позвать». Моти показывает обе лапки; Момо присматривается, подкрадывается, касается стекла одной лапкой и медленно моргает.
- **Находки Момо.** Доверьте коту папку с фотографиями: он уйдёт искать, принесёт снимок к стеклу и позволит поставить его в рамку в своей комнате. Можно попросить другую находку или открыть оригинал на ПК.
- **Устойчивая связь.** Кубик сохраняет домашнюю сеть и повторяет подключение после перезапуска или пропадания Wi-Fi.
- **Обновления из панели.** CubeDesk проверяет GitHub Releases при запуске и раз в час. Вы загружаете проверенный файл и выбираете момент установки. Приложение и прошивка обновляются независимо.

Панель работает только на `127.0.0.1`. Настройки, ключ подключения и медиатека остаются в `%LOCALAPPDATA%\CubeDesk`. Аккаунт GitHub для скачивания и обновления не нужен. Для погоды используется интернет; для локальных GIF и часов облако не требуется.

## Совместимость

- **Приложение:** Windows 10/11 x64. Воспроизведение требует работающего ПК.
- **Прошивка:** HelloCubic-Lite, ESP8266, 4 МБ flash, ST7789 240×240. Другие устройства GeekMagic не считаются автоматически совместимыми.
- **Штатная прошивка:** панель умеет загружать картинки и GIF с ограничениями штатной памяти. Виджеты, питомец и потоковый режим требуют PCStream.
- **Форматы:** JPG, PNG, BMP, WebP, GIF. MP4 и звук пока не поддерживаются.

**CubeDesk и PCStream версионируются отдельно:** это программа на ПК и прошивка кубика соответственно. В релиз 1.9.0 входят CubeDesk 1.9.0 и PCStream 1.8.1. Для работы в фоне обновлять прошивку не нужно. Они обновляются из панели отдельными кнопками.

## Обновления

Если установлена ранняя версия **1.6.0 или 1.6.1**, один раз закройте CubeDesk и замените `.exe` файлом из последнего релиза вручную: в этих версиях обнаружена проблема запуска помощника обновления. В 1.6.2 она исправлена.

Откройте «Обновления» → «Проверить обновления» → «Загрузить» → «Установить». Перед установкой проверяются репозиторий, тег релиза, размер и SHA-256 файла. При обновлении приложения настройки и медиатека сохраняются; не запустившаяся новая версия откатывается к предыдущему `.exe`.

Прошивка устанавливается отдельной кнопкой на совместимом устройстве с PCStream 1.6 или новее. Во время записи не отключайте питание. Первая замена штатной прошивки описана в [FIRST_FLASH.md](FIRST_FLASH.md).

## Разработчикам

```powershell
python -m pip install -r requirements-build.txt
python -m unittest discover -s tests -v
python start_cubedesk.py
```

Сборка готового релиза:

```powershell
python build_app.py
python -m platformio run -d firmware
python package_firmware.py
python release.py
```

Публичные файлы появляются только в `dist/release`. Рабочие `dist`, `backups`, локальные конфиги и приватные загрузочные значения в релиз не копируются. [Как выпускать новые версии](RELEASING.md). [Протокол потока](PROTOCOL.md). [Устройство первой настройки](ONBOARDING.md).
